# 差压液位计算小程序

用于差压液位计（隔膜双法兰、隔膜单法兰、引压管）量程与零点迁移计算，并支持法兰式膜片静压核验。提供**微信小程序**与 **Windows 桌面版（Electron）** 两种形态，全部计算在本机完成，无需登录或云服务。

- 微信小程序：`miniprogram/`
- Windows 桌面版：`desktop/`（可打包为 exe 安装包）

## 功能

- 支持隔膜双法兰、隔膜单法兰、引压管三种计算模式。
- 计算差压量程、零点迁移量及变送器调校范围（LRV、URV）。
- 自动判断正迁移、负迁移或无迁移。
- 考虑介质密度、隔离液/填充液、引压液柱、高低取压口高差及负压侧冷凝液。
- 双法兰与单法兰模式核验膜片静压是否在允许范围内。
- 液位跨度超过取压口高差时，差压量程自动按取压口高差截断计算，并给出预警提示。
- 展示输入参数、计算公式、数值代入过程和工程提示。
- 本机保存最近 20 次计算历史，支持恢复、单条删除和清空。

## 使用方法

1. 打开小程序，在“参数计算”页选择“隔膜双法兰”“隔膜单法兰”或“引压管”。
2. 按现场工况填写介质、液位、取压口和液柱参数。
3. 引压管模式根据负压侧情况选择是否存在冷凝液；法兰模式填写操作压力及膜片允许静压范围。
4. 点击“开始计算”，查看调校范围、差压量程、迁移量、静压核验和分步计算过程。
5. 在“计算历史”页可恢复历史参数并重新计算。

也可以点击“载入示例”填入一组示例参数。

## 输入参数与单位

| 参数 | 单位 | 说明 |
| --- | --- | --- |
| 介质密度 `ρ介质` | kg/m³ | 被测液体密度 |
| 最小液位 `h₀` | m | 最小液位相对高压取压口（单法兰为相对膜片安装点）的高度 |
| 液位跨度 `H` | m | 最大液位与最小液位之差 |
| 取压口高差 `Δh` | m | 低压取压口相对高压取压口的高度（仅双法兰、引压管） |
| 高压侧液柱 `hH` | m | 高压取压口高于变送器的距离；变送器较高时为负值（单法兰恒为 0） |
| 填充液/隔离液密度 `ρH` | kg/m³ | 双法兰填充液或高压侧隔离液密度 |
| 冷凝液密度 `ρL` | kg/m³ | 湿式引压管负压侧冷凝液密度 |
| 操作压力 | kPa(g) | 设备顶部气相表压 |
| 允许静压上下限 | kPa(g) | 膜片制造商允许的表压范围 |

重力加速度取 `g = 9.80665 m/s²`，计算压力统一输出为 kPa。

## 计算逻辑

### 1. 两侧等效液柱

双法兰及湿式引压管：

```text
hL = hH + Δh
```

干式引压管与单法兰（低压侧直通气相/大气）：

```text
hL = 0
```

液柱高度采用有符号数值，负值不取绝对值。

### 2. 差压量程

```text
ΔPspan = ρ介质 × g × H_eff / 1000
```

其中 `H_eff` 为有效量程跨度：当 `H ≤ Δh` 时 `H_eff = H`；当 `H > Δh` 时，差压变化范围受取压口高差限制，`H_eff = Δh`，量程按取压口高差截断计算。

除以 1000 用于将 Pa 转换为 kPa。

### 3. 零点迁移量

```text
ΔP₀ = ρ介质·g·h₀/1000 + ρH·g·hH/1000 − ρL·g·hL/1000
```

单法兰模式中膜片与变送器同高安装、无毛细管液柱，`hH = 0`，故迁移量仅含介质零点项：

```text
ΔP₀ = ρ介质·g·h₀/1000
```

迁移方向：

- `ΔP₀ > 0`：正迁移；
- `ΔP₀ < 0`：负迁移；
- `ΔP₀ = 0`：无迁移。

### 4. 调校范围

```text
LRV = ΔP₀
URV = ΔP₀ + ΔPspan
```

LRV 和 URV 分别对应最小、最大液位时的差压，通常对应变送器 4 mA 和 20 mA 输出。

### 5. 膜片静压核验（双法兰、单法兰）

按最大液位计算高压侧静压：

```text
PH = P操作 + ρ介质·g·(h₀ + H)/1000
PL = P操作
```

静压为设备介质在取压口处的表压，**不含毛细管/隔离液柱压力**。高、低压侧静压均须处于允许静压上下限之间，否则程序给出越限提示。

## 参数约束

- 密度和液位跨度必须大于 0，最小液位可为 0。
- 液位跨度允许超过取压口高差：当 `H > Δh` 时，差压量程自动按取压口高差 `Δh` 截断计算，并给出预警提示；当 `h₀ + H > Δh` 时给出最大液位越限预警。需确认最大液位未超出低压取压口、负压侧无介质倒灌。
- 膜片允许静压上限必须大于下限。
- 负液柱表示变送器高于相应取压口，程序会提示复核安装方向。
- 迁移量绝对值超过差压量程 2 倍时，程序给出工程核查提示。

## 桌面版打包

```bash
cd desktop
npm install
npm run dist   # 生成 dist/dp-level-calculator-1.0.0-setup.exe
```

打包产物为 NSIS 安装包（未签名，安装时 Windows 会提示"未知发布者"）。桌面版与小程序共用同一计算模型，计算结果一致。

## 运行测试

在安装 Node.js 的环境中执行：

```bash
node tests/calculator.test.js
```

当前测试覆盖双法兰、单法兰、干/湿式引压管、正负迁移、负液柱、静压越限、缺参及液位跨度超过取压口高差等 17 组场景。

## 注意事项

本程序用于工程核算，不替代设备制造商技术手册和现场设计规范。最终选型还应检查变送器允许迁移比、测量精度、温度影响、毛细管响应时间及膜片限值。操作压力和允许静压字段采用表压，填写前应避免与绝压混用。
